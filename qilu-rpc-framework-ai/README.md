# Qilu RPC Framework AI

Java RPC framework used by the Qilu services. The repository contains the RPC core and a Spring Boot starter for service registration, discovery, proxy invocation, retries, timeout handling, and remote error propagation.

This is an authorized secondary-development project. Keep `NOTICE` with distributed copies.

## Build

```powershell
mvn -f qilu-rpc-framework-ai/pom.xml clean test
```
